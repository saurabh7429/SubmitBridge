# Project Instructions & MCP Usage

## MCP Servers Integration Rules

Whenever writing code, generating documentation, building components, or running tests:

1. **Context7 MCP (`@upstash/context7-mcp`)**: Utilize Context7 MCP to fetch up-to-date framework documentation, library APIs, and context before and during code implementation.
2. **Playwright MCP (`@playwright/mcp@latest`)**: Utilize Playwright MCP for browser automation, UI verification, web scraping, and E2E testing.
